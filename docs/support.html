Frequently Asked Questions

How do I open files from Finder or the Dock?

You can drag any file onto the NoteEdit++ Dock icon, right-click any text or source code file in Finder and select Open With → NoteEdit++, or use the standard ⌘O shortcut within the app.

How does file saving work in the macOS App Sandbox?

NoteEdit++ is 100% sandboxed according to Apple security guidelines. When you open or save a file via the native Open/Save dialog, macOS securely grants NoteEdit++ permission to access that specific file. Your session and open tabs are preserved automatically.

How do I format JSON or XML?

Simply open your document, navigate to the Tools menu in the menu bar, and click Format JSON or Format XML. NoteEdit++ will validate and beautifully indent your markup in real time.

How do I split tabs into Dual View?

Press ⌥⌘D or right-click any document tab and select Dual View. This enables side-by-side editing so you can cross-reference multiple files simultaneously.
